# Advanced CSS3 & Responsive Portfolio

## Project Overview

This project is a modern, responsive personal portfolio created using semantic HTML5, advanced CSS3 and a small amount of JavaScript.

It is designed for the **Advanced CSS3 & Responsive Architecture** task.

## Key Features

- CSS Grid for two-dimensional page layouts
- Flexbox for navigation, buttons and component alignment
- Mobile-first responsive media queries
- CSS custom properties (variables)
- Light/Dark mode theme switcher
- Responsive hero section
- Responsive skills grid
- Complex project grid with different column spans
- Responsive contact form
- Hover transitions and visual effects
- Semantic HTML5 structure
- Accessibility-friendly labels and navigation
- Reduced-motion support

## Files

- `index.html` - Complete working portfolio containing HTML, CSS and JavaScript.
- `README.md` - Project documentation and submission instructions.

## How to Run

1. Download `index.html`.
2. Open the file in Chrome, Edge or Firefox.
3. Resize the browser window to test the responsive design.
4. Click the moon/sun button in the top-right corner to test dark mode.
5. Test the navigation links and contact form.

No installation, server or external library is required.

## Responsive Breakpoints

The page adapts at different screen sizes:

- **Desktop:** Full Grid-based layout
- **Tablet:** Two-column sections where appropriate
- **Mobile:** Single-column layout with stacked components
- **Small mobile:** Further adjustments for narrow screens

## CSS Architecture

### CSS Grid

Grid is used for:

- Hero section
- About section
- Skills section
- Projects section
- Contact section

The projects section uses a 12-column Grid to demonstrate different column spans.

### Flexbox

Flexbox is used for:

- Navigation alignment
- Navigation links
- Hero buttons
- Tags
- Contact items
- Component-level alignment

### CSS Variables

The `:root` selector contains reusable variables for:

- Background colors
- Surface colors
- Text colors
- Primary colors
- Borders
- Shadows
- Border radius
- Transitions

The `.dark` class changes these variables to create the dark theme.

### Media Queries

Responsive media queries change the layout for:

- Screens below 900px
- Screens below 650px
- Screens below 400px
